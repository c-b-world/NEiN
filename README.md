# NEiN防災
その一秒を、未来を守る力に。

災害は、予告なく日常を変える。
だからこそ、私たちは情報の可能性を追求する。

NEiN防災は、地震・津波を基本とする自然災害に関する情報を、迅速かつ直感的に届けることを目指す次世代型防災情報プラットフォームです。

膨大な観測情報を集約し、複雑な情報を可視化することで、災害発生時における状況把握と的確な判断を支援します。

迅速性、視認性、信頼性。
そのすべてを追求し、情報と人命をつなぐ新たな防災基盤の構築を目指します。

私たちは、災害そのものを止めることはできない。
しかし、情報によって、その先の未来を変えることはできる。

**情報を、力に。技術を、命のために。**

*NEiN — Beyond the Limits of Disaster Intelligence.*
